# scokabu-data

iOSアプリ「スコカブ」向けの機械生成データフィードです。

- `v1/rankings.json` — 日本株・米国株のスコアランキング（1日2回更新）
- 内容はアプリ独自のスコア（0-100）・前日比%・出来高倍率などの**派生値のみ**で、株価・気配等の生の相場情報は含みません
- スコアは公開情報の機械的な集計であり、銘柄の推奨・投資助言ではありません。正確性・完全性・継続性は保証されません
- 本データのアプリ外での利用・再配布はご遠慮ください

Auto-generated data feed for the ScoKabu iOS app. Derived scores only (no raw market data). Not investment advice. No warranty. Please do not reuse or redistribute.
